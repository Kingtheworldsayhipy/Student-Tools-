Operators and quick reference

Any of these spellings work.

Constants: 0, 1, TRUE, FALSE. Variables are single letters A–Z (case-insensitive). Put spaces around words such as AND, OR so they are not read as separate letters.

Order of operations

  1. Parentheses ( )
  2. NOT (also A')
  3. AND, NAND (also letters side by side)
  4. XOR, XNOR
  5. OR, NOR
  6. Implication (→), right to left
  7. Equivalence (↔)

When unsure, add parentheses.
